GET /api/v1/metadata

Dataset version and update info.

curl "{{ request.url_root }}api/v1/metadata"

GET /api/v1/whatif

Live rank estimate + top 5 colleges for a CGPA.

curl "{{ request.url_root }}api/v1/whatif?cgpa=8.2&category=UR&gender=M&college_type=Any"

GET /api/v1/predict

Full college prediction (max 30 per year).

curl "{{ request.url_root }}api/v1/predict?cgpa=8.0&category=UR&gender=M&branch=CSE"

GET /api/v1/smart-choices

Safe / Target / Dream choice buckets.

curl "{{ request.url_root }}api/v1/smart-choices?cgpa=8.0&category=UR&gender=M"

GET /api/v1/colleges/search?q=...

Search colleges by name (min 2 chars).

curl "{{ request.url_root }}api/v1/colleges/search?q=sgsits"

GET /api/v1/colleges/detail?name=...

College detail with chart, heatmap, fee data.

curl "{{ request.url_root }}api/v1/colleges/detail?name=Shri+G.S.+Institute..."

GET/POST /api/v1/reviews

College alumni notes (GET by college_name, POST to add).

GET /api/v1/counselling-schedule

Important counselling dates for notifications.

GET/POST /api/v1/shortlist/cloud

Auth required. Sync shortlist to user account.

POST /api/v1/colleges/google-enrich

Fetch one college from Google Places API (needs GOOGLE_MAPS_API_KEY on server).

curl -X POST {{ request.url_root }}api/v1/colleges/google-enrich -H "Content-Type: application/json" -d "{\"college_name\": \"SGSITS Indore\"}"

Data Sources

  • Cutoffs & ranks: DTE MP official counselling PDFs
  • Address, phone, Maps, website: Google Places API (scripts/enrich_colleges_google.py)
  • Driving distance: Google Distance Matrix API (or city estimate without key)
  • Fees: Official college websites + verified listings — Google does not provide tuition

Rate limit: please cache responses. Data is for educational use only — not affiliated with DTE MP.
